# Jasmine demo assets (Phase B3 Task 5)

The 24 WebP files in `assets/` are AI-generated ILLUSTRATIVE samples (Ruling TPL-3) for the
`storedemo-jasmine` showroom: they are not a real merchant's products and show no real brand.

- **Model / how:** FLUX.1 schnell on Cloudflare Workers AI (`@cf/black-forest-labs/flux-1-schnell`,
  8 steps), offline, by `gen.py` from the prompts in `prompts.py`; `encode.sh` crops (1:1 products,
  16:9 heroes), caps the long edge at 1200 px and encodes with `cwebp` (each file <= 140 KB, the
  whole set <= 8 MB). No stock photo, no third-party image and no real person is used.
- **Unbranded (Ruling B3-9):** no logo, lettering or readable label. FLUX invents text on labels, so
  every file was viewed before commit and any text artefact was regenerated (`lip-oil` and
  `hero-clinic` each took a second pass for invented lettering).
- **No orange, amber, coral or peach (Rulings B3-2, B3-3):** glass is clear, jade or cobalt, never
  amber or brown; liquids are water-clear or pink, never golden. FLUX ignores negated colour words
  (asking for "no amber" produced amber), so the prompts only name the colours wanted. Four first
  passes were regenerated by eye for amber, golden or coral tones (`oud-rose-perfume`,
  `argan-hair-oil`, `cream-blush`, `hero-bloom`); `orange-probe.py` (hue 12-50, saturation >= 0.35,
  value >= 0.25) measures every file: <= 3 % per product, <= 5 % per hero, enforced by
  `tests/unit/jasmine-demo-assets.test.ts` with a negative control.
- **No faces, hands or skin close-ups (Ruling B3-3):** product-only and still-life compositions.
- **Apothecary hero:** the plan's "brass caps" became brushed SILVER caps: brass is orange-family
  and FLUX paints it as saturated amber. The brass stays a UI colour only (Ruling B3-2).
- **Served from:** locally `JASMINE_DEMO_ASSET_BASE=/__jasmine-demo` (an untracked copy under
  `apps/web/public/__jasmine-demo/`, deleted afterwards); in production the R2 prefix
  `demo/jasmine/` (`https://media.ebda.app/demo/jasmine`), uploaded by the controller after merge.
