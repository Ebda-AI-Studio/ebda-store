Fonts are set in the visual editor, not on a separate page. Open **Builder**, choose **Fonts**, pick a font for each area (headings, body, prices) and publish. You can upload a font file of your own; check that the font has Arabic letters and that you have the licence to use it online.

Fonts are saved when you publish, so you can preview first and go back from the page history.

## Ask the assistant
The assistant can show you where fonts live, but it does not change fonts: they are saved only through the editor's publish step.
