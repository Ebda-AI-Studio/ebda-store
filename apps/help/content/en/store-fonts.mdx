Fonts are set in the **visual editor** (**Store look** in the side menu), and only the store owner can open it. Changes are saved as a draft and visitors see them when you press **Publish**.

## Add a font

1. Open **Store look**, then the **Colours and fonts** tab.
2. Open **Advanced: fonts, text styles and more**. Or type "font" in the **Search settings** box.
3. In the **Fonts** card choose:
   - **+ Add Google Font**: type the **Font family name** (for example Cairo). The Google Fonts URL is optional and is built from the name. Then **Add font**.
   - **Upload custom font**: type the **Font family name (display label)** and choose the **Font file** in **woff2**, **woff**, **ttf** or **otf** format, up to **5 MB**, then **Upload font**.
4. Each font in the list has a **Google** or **Custom** tag and a **Remove** button.

Uploading a file only stores it. The font does not work in your store until you press **Publish**. The whole font list is saved with the draft.

## Use the font

Below the Fonts card are the text styles by area: announcement bar, page header, store name, section heading, products, product name and price, buttons, filters, footer. For each zone:

- **Font family**: a text box, type the family name exactly as you added it.
- **Font size**: 12, 14, 16, 18 or 22px.
- **Font weight**: 400 regular, 600 semi-bold, 700 bold.
- **Letter spacing**, **Line height**, **Text transform**, **Text decoration** and **Text alignment**.
- **Reset to default** returns the zone to your store look.

## Common questions

**The font did not show.** Make sure you pressed **Publish**, and that the family name in **Font family** matches the one in the list.

**The font looks good in English and breaks Arabic.** Choose a font that supports Arabic letters. Also make sure you have the right to use the font before you upload it.

**The upload failed.** The file must be one of the four types and under 5 MB.

**I want the old look back.** From **History** you can go back to an older version (see [Page versions and restore](/en/page-versions-and-restore/)), and for the other controls see [Fine-tune your store look](/en/store-look-controls/).
