Tags are the small chips your customers filter your products by, like skin type or concern. Each tag has an English and an Arabic name, and the storefront shows the one that matches the shopper's language.

## Who can do this

The store owner only. The **Tags** page does not open for staff accounts.

## Where tags come from

The **Tags** page has no button to create a new tag. Tags are created from the product form, bulk import or the AI tagger. If the page is empty it says so and shows a **Go to products** button. Use the page to review the tags you have and rename them.

## Rename a tag

1. Open **Tags** in your store. You see a table with **Name (English)**, **Name (Arabic)** and the number of **Products** on each tag.
2. Change the name in the field you want. A name can be up to 80 characters.
3. Press **Save** on the same row. The button only works once you changed something. You see "Saved".

The English name is also the filter key in your store link, so changing it changes what your customer sees and filters by.

## When a tag has no Arabic name

A note appears under the field: "No Arabic label: Arabic shoppers see the English name." Type the Arabic name yourself, or use the AI translate button at the top of the page, which fills the missing names. Check the translation, then press **Save** on each row.

## If something goes wrong

- **Another tag already uses this name:** pick a different name, because every tag in a store must have a unique name.
- **Could not save the tag:** refresh the page and try again.
