Both exports are for the store owner. They carry customers' names, phones and addresses, so team members do not get the option.

## Export orders

1. Open **Orders** under **Sales**.
2. Choose the period, status and search you want. The file matches what is on screen.
3. Press the **...** menu (**More order options**), then **Export orders**.

The file has two sheets: **Orders** with one row per order, newest first, and **Line Items** with one row per product in each order.

## Export customers

1. Open **Customers** under **Sales**.
2. Apply a search or segment if you want only part of the list.
3. Press the **...** menu (**More customer options**), then **Export Excel**.

## Good to know

- Every download is recorded in the audit log, because it contains personal data.
- Orders: up to the latest 20,000. If you have more, the first sheet ends with a note saying the export was cut.
- The customer export is disabled while the list is loading or empty.
- If it fails you see "Export failed". Try again.
