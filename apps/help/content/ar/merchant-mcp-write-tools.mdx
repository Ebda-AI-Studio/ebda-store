## ده إيه

MCP التاجر بيوصّل Claude، أو أي مساعد بيدعم MCP، بمتجرك عن طريق مفتاح API بدل ما تفتح لوحة التحكم. القراءة (الطلبات والمنتجات والتحليلات) متاحة لأي مفتاح سليم. **أدوات الكتابة** بتخلّي نفس المساعد يعمل تعديلات، زي ما موظف عندك بيعمل من اللوحة.

المساعد عمره ما بياخد صلاحية أكتر من الشخص اللي عمل المفتاح. لو اللي عمله موظف (**staff**) مش بيقدر يمسح منتجات من اللوحة، المفتاح كمان مش هيقدر يمسحها.

## الباقات وزرار التشغيل

- MCP التاجر، قراءة وكتابة وإصدار المفاتيح، موجود في باقتي **النمو** و**الأعمال**. الباقة الأساسية مش فيها.
- القرار بتاعك لكل متجر: افتح صفحة **مفاتيح MCP للتاجر** واستخدم **زرار أدوات الكتابة** اللي فوق. لو قفلته، كل المفاتيح تبقى للقراءة بس فورًا. فريق المنصة كمان يقدر يقفلها لمتجرك من صفحة المزايا.
- المفتاح كمان لازم يكون معاه الصلاحية المناسبة: `merchant:write` للتعديلات العادية، و`merchant:destructive` للحذف والإلغاء والاسترداد. مفتاح اتعمل للتقارير بس (`merchant:read`) مايقدرش يغيّر أي حاجة.

## خطوة التأكيد (الحذف والإلغاء والاسترداد)

فيه إجراءات صعب الرجوع فيها، فالمساعد مايقدرش ينفذها من أول مرة:

1. المساعد بينادي الأداة (مثلًا `admin_delete_product`) برقم المنتج.
2. **مفيش حاجة بتتغيّر.** الأداة بترد بملخص قصير لإيه اللي هيحصل بالظبط، ومعاه **رمز تأكيد**.
3. المساعد بيعرض عليك الملخص. لو وافقت، بينادي نفس الأداة تاني بنفس البيانات ومعاها الرمز، وساعتها بس الإجراء بيتنفذ.

الرمز بيشتغل **مرة واحدة** و**لمدة دقيقتين**، ولـ**نفس الإجراء على نفس العنصر** ومن نفس المفتاح. رمز طلب (أ) مايلغيش طلب (ب)، والرمز المستخدم مايتعادش، ولو أي بيان اتغيّر بيرجع لك ملخص جديد بدل ما ينفذ.

## الأدوات

| الأداة                       | بتعمل إيه                                            | محتاجة تأكيد |
| ---------------------------- | ---------------------------------------------------- | ------------ |
| `admin_update_order_status`  | تنقل الطلب لـ مؤكد أو قيد التجهيز أو اتشحن أو اتسلّم | لأ           |
| `admin_cancel_order`         | تلغي طلب، وتقدر ترجّع المخزون                        | أيوه         |
| `admin_create_product`       | تضيف منتج (نفس حقول وفحوصات نموذج اللوحة)            | لأ           |
| `admin_update_product`       | تعدّل بيانات منتج                                    | لأ           |
| `admin_delete_product`       | تمسح منتج                                            | أيوه         |
| `admin_adjust_inventory`     | تزوّد أو تنقّص المخزون بكمية مع سبب                  | لأ           |
| `admin_set_inventory`        | تضبط المخزون على عدد محدد                            | لأ           |
| `admin_create_coupon`        | تعمل كوبون خصم                                       | لأ           |
| `admin_update_coupon`        | تعدّل كوبون                                          | لأ           |
| `admin_toggle_coupon`        | تشغّل الكوبون أو توقفه                               | لأ           |
| `admin_delete_coupon`        | تمسح كوبون                                           | أيوه         |
| `admin_approve_return`       | توافق على طلب مرتجع                                  | لأ           |
| `admin_reject_return`        | ترفض مرتجع (لازم تكتب السبب)                         | لأ           |
| `admin_mark_return_received` | تسجّل إن البضاعة المرتجعة وصلت                       | لأ           |
| `admin_complete_return`      | تكمّل المرتجع وترجّع الفلوس للعميل                   | أيوه         |

كل أداة بتشغّل نفس الكود ونفس الفحوصات بتاعة الإجراء المقابل في اللوحة، ومابتلمسش غير متجرك إنت.

## الفلوس

مدفوعات العملاء إنت اللي بتوافق عليها، المساعد لأ. المساعد يقدر يرجّع فلوس بس من خلال مرتجع بتكمّله (هو أو إنت) بتأكيدك، وبنفس طرق الاسترداد وقواعدها في اللوحة. الاسترداد على وسيلة الدفع الأصلية للعميل، أو كرصيد في المحفظة (store credit)، محتاج صلاحية **orders:refund** (صاحب المتجر)، والموظفين معندهمش الصلاحية دي. تسجيل الطلب كمدفوع، وتأكيد إيصالات إنستاباي، والاسترداد مباشرة من الطلب **مش متاحين** عن طريق MCP.

## لسه مش متاح

الإجراءات دي مش متاحة عن طريق MCP، غالبًا لأن منطقها لسه جوه شاشة اللوحة مش في خدمة مشتركة. اعملها من اللوحة دلوقتي.

| المجال                                                    | ليه لسه                                   |
| --------------------------------------------------------- | ----------------------------------------- |
| الأقسام (إضافة وتعديل وحذف وترتيب)                        | المنطق لسه مش مشترك، وجاي في اللي بعده    |
| متغيرات المنتج والتعديل الجماعي للمنتجات                  | جاي بعد كده، والجماعي هيحتاج خطوة التأكيد |
| ملاحظات الطلب والتجهيز والتتبع والفواتير                  | جاي بعد كده                               |
| تسجيل مدفوع، تأكيد إنستاباي، استرداد من الطلب             | بتحرّك فلوس العملاء، من اللوحة بس         |
| العملاء (تعديل ومسح وتصدير)                               | بيانات شخصية، من اللوحة بس                |
| إعدادات المتجر والدفع والشحن والموظفين والدومين والفواتير | إعدادات أمان وفلوس، من اللوحة بس          |
| الصفحات ومنشئ المحتوى                                     | جاي بعد كده                               |
| إدارة المنصة                                              | مش هتتاح أبدًا                            |

## الحدود والسجلات

- الكتابة محدودة بـ 30 عملية في الدقيقة لكل مفتاح، وأي طلب بيجمّع كذا عملية كتابة مع بعض بيتم رفضه.
- كل عملية كتابة بتتسجّل في سجل التدقيق باسم المفتاح اللي نفّذها وعلامة إنها جت من مساعد ذكاء اصطناعي. التسجيل بيحصل **قبل** التغيير؛ ولو التسجيل ماتمش، التغيير مابيتنفذش.

## إيقافها

استخدم زرار أدوات الكتابة في صفحة **مفاتيح MCP للتاجر**، أو الغي المفتاح. القراءة تفضل شغالة، وكل أدوات الكتابة بترفض فورًا.
