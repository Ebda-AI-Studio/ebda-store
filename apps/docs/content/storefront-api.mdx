Base: `https://api.ebda.app/api/v1/public`. Name the store with the `x-store-domain` (or `x-store-id`) header, see [Authentication](/authentication/). Reads are rate limited at 300 requests per minute per IP.

## Catalogue

| Method | Path                  | Notes                                                                                                                                                                                                                                                                                                                             |
| ------ | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`  | `/health`             | Liveness and database check. `200`, or `503` when the database is unreachable                                                                                                                                                                                                                                                     |
| `GET`  | `/products`           | Paginated. Query: `page`, `limit` (max 100), `category`, `search` (2+ characters), `featured`, `sort` (`newest`, `price_asc`, `price_desc`, `best_seller`, `on_sale` — products whose compare-at price is above their price, biggest drop first, at most 12, first page only), `minPrice`, `maxPrice` (piastres), `cursor`, `ids` |
| `GET`  | `/products/:slugOrId` | One product with variants and images                                                                                                                                                                                                                                                                                              |
| `GET`  | `/categories`         | Category tree                                                                                                                                                                                                                                                                                                                     |
| `GET`  | `/feed/products.json` | AI product feed (needs the `agent_feed` feature, paid plans)                                                                                                                                                                                                                                                                      |
| `GET`  | `/feed/google.xml`    | Product feed for Google Merchant Center (RSS 2.0, needs `product_feeds`, paid plans). Query: `lang` (`ar` or `en`), `part`. Also `/feed/meta.xml` and `/feed/tiktok.csv`                                                                                                                                                          |
| `GET`  | `/redirects/resolve`  | Resolve a renamed store slug                                                                                                                                                                                                                                                                                                      |
| `GET`  | `/stores`             | Active stores, paginated (`page`, `limit` up to 100)                                                                                                                                                                                                                                                                              |
| `GET`  | `/stores/:slugOrId`   | Public store profile. Reserved slugs return `404 STORE_NOT_FOUND`                                                                                                                                                                                                                                                                 |

## Cart

Cart endpoints are limited to 30 per minute.

| Method   | Path          | Notes                               |
| -------- | ------------- | ----------------------------------- |
| `GET`    | `/cart`       | Current cart                        |
| `POST`   | `/cart/items` | Add an item                         |
| `POST`   | `/cart/sync`  | Replace the cart from a client copy |
| `DELETE` | `/cart`       | Empty the cart                      |

Product prices in responses are integer piastres, see [Money](/money/).

```bash
curl "https://api.ebda.app/api/v1/public/products?limit=5&sort=newest" \
  -H "x-store-domain: amelia.ebda.app"
```
