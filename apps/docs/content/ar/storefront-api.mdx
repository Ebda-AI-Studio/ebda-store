الأساس: `https://api.ebda.app/api/v1/public`. سمِّ المتجر بالهيدر `x-store-domain` (أو `x-store-id`)، راجع [المصادقة](/ar/authentication/). القراءات محدودة بـ 300 طلب في الدقيقة لكل IP.

## الكتالوج

| الطريقة | المسار                | ملاحظات                                                                                                                                                                                                                                                                                                                                       |
| ------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`   | `/health`             | فحص الحياة وقاعدة البيانات. يعيد `200`، أو `503` إذا تعذّر الوصول لقاعدة البيانات                                                                                                                                                                                                                                                             |
| `GET`   | `/products`           | مقسَّم لصفحات. المعاملات: `page`، `limit` (الحد الأقصى 100)، `category`، `search` (حرفان فأكثر)، `featured`، `sort` (`newest` و`price_asc` و`price_desc` و`best_seller` و`on_sale` وهو المنتجات التي سعر المقارنة فيها أعلى من سعرها، الأكبر خصماً أولاً، بحد أقصى 12، وللصفحة الأولى فقط)، `minPrice` و`maxPrice` (بالقروش)، `cursor`، `ids` |
| `GET`   | `/products/:slugOrId` | منتج واحد مع متغيراته وصوره                                                                                                                                                                                                                                                                                                                   |
| `GET`   | `/categories`         | شجرة الأقسام                                                                                                                                                                                                                                                                                                                                  |
| `GET`   | `/feed/products.json` | تغذية منتجات للذكاء الاصطناعي (تحتاج ميزة `agent_feed`، في الباقات المدفوعة)                                                                                                                                                                                                                                                                  |
| `GET`   | `/feed/google.xml`    | خلاصة منتجات لـ Google Merchant Center (RSS 2.0، تحتاج ميزة `product_feeds`، في الباقات المدفوعة). المعاملات: `lang` (`ar` أو `en`) و`part`. وكمان `/feed/meta.xml` و`/feed/tiktok.csv`                                                                                                                                                       |
| `GET`   | `/redirects/resolve`  | تحويل slug متجر تغيّر اسمه إلى الاسم الحالي                                                                                                                                                                                                                                                                                                   |
| `GET`   | `/stores`             | المتاجر الفعّالة، مقسَّمة لصفحات (`page`، و`limit` حتى 100)                                                                                                                                                                                                                                                                                   |
| `GET`   | `/stores/:slugOrId`   | الملف العام للمتجر. الـ slug المحجوزة تعيد `404 STORE_NOT_FOUND`                                                                                                                                                                                                                                                                              |

## السلة

نقاط السلة محدودة بـ 30 طلباً في الدقيقة.

| الطريقة  | المسار        | ملاحظات                       |
| -------- | ------------- | ----------------------------- |
| `GET`    | `/cart`       | السلة الحالية                 |
| `POST`   | `/cart/items` | إضافة عنصر                    |
| `POST`   | `/cart/sync`  | استبدال السلة بنسخة من العميل |
| `DELETE` | `/cart`       | تفريغ السلة                   |

أسعار المنتجات في الاستجابات أعداد صحيحة بالقروش، راجع [المبالغ](/ar/money/).

```bash
curl "https://api.ebda.app/api/v1/public/products?limit=5&sort=newest" \
  -H "x-store-domain: amelia.ebda.app"
```
