Ebda Store is a self-serve store builder for Egyptian merchants. Every store lives at `<slug>.ebda.app` (or on its own custom domain) and is backed by one multi-tenant HTTP API at `https://api.ebda.app/api/v1`.

These docs describe what the API does **today**. Where something is planned but not built (Egyptian payment providers, carrier integrations) the page says so rather than documenting an interface that does not exist yet.
