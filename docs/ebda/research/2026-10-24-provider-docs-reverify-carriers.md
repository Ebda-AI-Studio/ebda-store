## Carriers

Ruling PROVIDERS-3, shipping carriers re-verified 2026-10-24 against each carrier's current official docs. Status: **OK** = docs read and the adapter matches; **FIXED** = adapter was out of date and is corrected in this PR (failing contract test first); **UNCONFIRMED** = the official docs are silent, adapter stays fail-safe, first merchant with real credentials settles it. `verified` / `sandboxVerifiedAt` are NOT flipped for any carrier (no real account has run yet). Each `verification.note` in `packages/shared/src/providers/catalog.ts` carries the same result.
