## (b) Drift found between the contracts and the current plan-feature-matrix

**Plan → feature tier mapping: no drift.** I extracted the full Starter/Professional/Enterprise
item lists from both the Force Store quote and contract templates' embedded JS and checked every
plan-gated line against `docs/business/plan-feature-matrix.md`:

- Loyalty, push notifications, upsell/cross-sell → appear starting at **Professional** in both
  templates. Matches matrix (`loyalty`, `push_notifications`, `upsell_crosssell` = Professional+).
- Affiliate, SMS, Floating Widget → appear only at **Enterprise** in both templates. Matches
  matrix (`affiliate`, `sms`, `floating_widget` = Enterprise-only).
- Accounting: Starter has none; Professional gets "أساسي: CoA + دفتر اليومية + P&L + المصروفات +
  الفوترة" (basic/expenses/invoicing); Enterprise gets the same plus "تقارير الضرائب، تعدد
  العملات، مراقبة شذوذ الأرباح، مطابقة الحسابات البنكية" (tax reports/multi-currency/profit
  anomaly/bank reconciliation). Matches matrix exactly (`accounting.basic/expenses/invoicing` =
  Professional+, `accounting.tax_reports/multi_currency/profit_anomaly/bank_reconcile` =
  Enterprise-only).
- Inventory: Starter/Professional describe basic management; Professional adds "تنبيهات نفاد
  المخزون والطلب المسبق" (stock alerts + backorder); Enterprise adds "مستودعات متعددة، الباركود،
  أوامر الشراء، التسويات الجماعية" (multi-warehouse/barcode/purchase orders/bulk adjustments).
  Matches matrix exactly.
- No self-serve or free-trial language anywhere in any of the 4 templates — consistent with the
  managed-agency, one-time-yearly-fee model. ✅
- WhatsApp ordering bot is described as the native Meta Commerce catalog flow ("الكتالوج
  التفاعلي الرسمي من Meta (WhatsApp Native Catalog)") in both the Store and WhatsApp templates —
  the old "send an image per category" flow does not appear anywhere. ✅
- SLA terms (99.5% uptime, 24h/4h response, service-day credit capped at 30 days/year), Kuwait
  Law 13/2023 data-processor language, and payment terms (bank transfer/certified cheque, no
  monthly subscription) all read exactly as `CONTRACT-CHECKLIST.md` describes as
  "verified accurate" — matches, no drift, **left untouched per instructions.**
