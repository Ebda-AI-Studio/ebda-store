# B2-11

> Section: 2026-10-21 — Phase B2 Souq (B2-\*)

Ruling B2-11 (made while implementing Task 1) — the no-orange gate measures saturation as HSV chroma/value, not HSL. The plan wrote HSL, but HSL saturation of a near-white cream reads 50% for `#F6F3EA` (hue 45) although its chroma is 5% of its value: an HSL gate flags Night's own page ink and the cream `secondaryForeground`. Orange `#E68245` is 70% and brass `#C89B3C` is 70% by HSV, so the gate keeps its teeth (negative control) without flagging paper. Cost if wrong: a pale peach tint (value > 95%, chroma < 35%) would pass; it is not a colour a look can pick without a token edit that a reviewer sees.
