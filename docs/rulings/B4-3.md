# B4-3

> Section: 2026-10-22 — Phase B4 Lamma (B4-\*)

Ruling B4-3 — food-calibrated orange probe. Pixel counts as "orange" when hue 12°–45°, HSV saturation ≥ 0.65 and value ≥ 0.60; limit ≤ 4% for product/category photos, ≤ 6% for heroes, page-wide shots ≤ 6%. Browns, crust and caramel (lower saturation or value) pass; a glowing orange (lanterns, oranges, carrots) fails. The Souq probe (strict) is not reused as-is because it would reject any bread. A negative-control fixture must fail. Cost if wrong: a golden-orange dish passes the probe — mitigated by viewing every image and by the Audit-2 rendered-shot check.
