Ruling CATIMP-2 - the monthly page allowance is `plans.limits.catalogImportPagesPerMonth` (Free 0, Basic 100, Growth 400, Pro 400, Business 1500, comped and founding_free unlimited), `.default(0)` so an old blob means OFF, never unlimited; it is read by the page ledger and is NOT a gated write or a feature key (no `catalog_import` feature, no plan-baseline or message-table churn). Per-job, per-day and per-file numbers are env defaults (docs/ENVIRONMENT.md). Every model call that returns a reply adds the file's pages to `charged_pages`, so a retry that reaches the model is charged again; a retry that fails before the model is called is free; attempts are capped at 3 per file. Evidence: tests/unit/catalog-import-plan-limits.test.ts, tests/integration/catalog-import.test.ts (retries are bounded and charged). Cost if wrong: a plan number is a SQL update away; charging every model-reaching retry can annoy a merchant whose file keeps failing, which the 3-attempt cap bounds.
