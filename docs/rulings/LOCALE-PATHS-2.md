Ruling LOCALE-PATHS-2 - amends LOCALE-PATHS-1 (controller close-all program 2026-10-29, Track S1, Ahmad's "before launch" intent): a LONE `all` in `STOREFRONT_LOCALE_PATHS_STORES` opts every store host in, and the web deploy now passes `STOREFRONT_LOCALE_PATHS=true` + `STOREFRONT_LOCALE_PATHS_STORES=all` as plain Worker vars on every `wrangler deploy` (repo variables of the same names override them; `STOREFRONT_LOCALE_PATHS=false` is the one-switch rollback). `all` mixed with any other token stays unparseable (fail-closed, a typo cannot half-widen), and the master flag still gates it. Only store hosts (`<slug>.ebda.app`, custom domains) reach this gate; platform hosts never do. The store's default language stays its own `settings.defaultLanguage`, so nothing per store is configured. Evidence: `tests/unit/web-locale-paths.test.ts`, `tests/unit/cf-web-deploy-vars.test.ts`, local-build check in the PR. Cost if wrong: every store's indexable URLs move to `/ar|/en` at once (old URLs 301, Search Console re-learns the sitemap), so a bug in the prefix logic hits all stores instead of one canary; rollback is the repo variable `STOREFRONT_LOCALE_PATHS=false` plus a web deploy.
