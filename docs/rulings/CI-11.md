Ruling CI-11 (Store session, 2026-10-29; CI-2/CI-3) - weekly calibration (predicted band vs actual return rate, off by more than 10 points with >= 30 resolved hints) is evaluated only when the band meets the cohort rules (>= 5 distinct stores, none above 40% of the band) and it ALERTS; it never closes a platform gate. Closing a gate is a super-admin decision (`/ci-insights`). Security review: one store feeding skewed outcomes must not be able to switch a feature off for every store. Per-store auto-gating is not built; a store that wants no hints turns its own switch off. Tests: a single-store skew alerts nobody; a below-k band is not evaluated; the service source has no path to the gate. Cost if wrong: a genuinely mis-calibrated hint stays on until a super-admin acts on the alert.
