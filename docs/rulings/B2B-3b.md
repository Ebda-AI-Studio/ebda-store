# B2B-3b

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-3b - Lowest merchant-authored price visible to this buyer at this quantity; specificity decides only within one audience; no stacking (replaces the selection step of B2B-3). (1) `pub` = best PUBLIC tier (variant-level beats product-level, then the lowest price, then the smaller minQty); (2) `gTier` = the same over the buyer's active-group tiers; (3) `gPct` = group percent off base; (4) `unit = min(pub, gTier, gPct)` clamped to `[0, base]`; (5) provenance tie-break gTier -> gPct -> pub; `unit == base` reports `base`. A tier is a candidate only if its minQty is reached, its price is `< base` (a stale / useless tier is dropped, so it cannot mask the group %), and a product-level tier applies only when `base == product.price` (a variant with its own price needs variant-level tiers). Guarantees (property tests): `0 <= unit <= base`; `unit(group buyer) <= unit(anonymous)`; unit is always one of base / a tier price / the percent price; independent of input order. Cost if wrong: a merchant who deliberately set a group tier dearer than the public break sees the cheaper public price win; the line records `price_source` so it is explainable.
