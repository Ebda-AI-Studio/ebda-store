# CONTACT-FORM-1

Ruling CONTACT-FORM-1 - the Ebda AI Studio service-enquiry form on `/contact` and `/en/contact` posts to `POST /api/v1/public/contact/enquiry` and is mail-only: no table, no stored enquiry, no new provider. Ahmad approved the form 2026-11-03. Decisions: (1) delivery is the platform email path (`EmailService.sendContactEnquiry` through `mail-transport`, Cloudflare Email Service) to `BRAND.supportEmail` (ahlan@ebda.app) with Reply-To the visitor, sent directly and awaited, never queued, so "sent" is only ever shown after the send resolved; a failed send is a 502 `SEND_FAILED`, a P1 alert (`public.contact.enquiry`, request id only) and a page message pointing to WhatsApp/email; the visitor's receipt is best effort and never turns a delivered enquiry into an error. (2) Spam: the repo has no Turnstile secret or binding (only a note in S4-1), so no third-party widget is added: a CSS-hidden honeypot (fake success, no email), a minimum fill time (the page reports how long it was open; under 2.5 s is refused as `TOO_FAST`, absent for the no-JavaScript post) and 5/hour per IP and 5/hour per normalised email through the repo's existing store-backed rate limiter. (3) Privacy: zod validation and length caps at the edge, E.164 phone and lower-cased email, control characters stripped from single-line fields, every value HTML-escaped in the templates, and logs and the alert carry a request id and an outcome only. (4) Marketing CSP is `frame-ancestors 'none'; form-action 'self' https://api.ebda.app` (the static export had no script/connect policy and none was added, so the form needs no new origin). (5) The form is a real `<form method=post action=API>`: without JavaScript the API 303s to a fixed `https://ebda.app[/en]/contact/#sent` or `#send-failed` (static `:target` panels); with JavaScript it validates, posts JSON and shows a `role=status` result. Evidence: `tests/unit/contact-enquiry-route.test.ts`, `contact-enquiry-limiters.test.ts`, `contact-enquiry-shared.test.ts`, `marketing-contact-form.test.tsx`, `marketing-contact-page-and-csp.test.tsx`; `docs/api/studio-enquiry.md`. Accepted residuals: a patient human spammer passes a honeypot and 5/hour, and a script that omits `fillMs` skips the fill-time check (the same as a no-JavaScript visitor); add a bot challenge (Turnstile needs a site key and secret from Ahmad) if the studio inbox sees abuse. Cost if wrong: a real enquiry is refused as too fast or rate-limited and the visitor must retry or use WhatsApp, or the studio inbox gets some spam before a challenge is added.
