# MKT-REDIRECT-307

> Section: Pre-QA sweep 2026-11-10 (branch `fix/preqa-p2-batch`), finding 13: ebda.app answers 307, not 308, when a page is asked for without its trailing slash

Ruling MKT-REDIRECT-307 - the 307 stays for launch; it is not changed to 308 in this batch. Measured in production 2026-11-10: `GET https://ebda.app/legal`, `/privacy`, `/terms`, `/en` and `/services` each answer `307` with `location: <path>/` and no `cache-control`, and the slash form answers `200`. The status is not ours: the marketing site is a static export served by Workers Static Assets with no Worker script (`apps/marketing/wrangler.jsonc`, `html_handling: auto-trailing-slash`), and that setting has four modes and no status option, so the platform picks 307. What was checked before deciding: (1) method handling: `POST /legal` and `POST /legal/` both answer `405`, the site has no form endpoint, so a method-preserving redirect has nothing to preserve and 307 against 308 changes nothing for a POST. (2) Caching: the 307 carries no `cache-control`, so a browser asks again each time; a 308 is kept by browsers with no expiry, so a wrong one cannot be recalled from a visitor's device. (3) Reach: the canonical link of `/legal/` is the slash form, all 64 `<loc>` entries of `sitemap.xml` end in a slash, and the home page has no internal page link without one, so only a hand-typed or outside link ever meets the redirect, and it is one hop. The two ways to get a 308 are both a routing change to every page of the site: one `_redirects` line per page and language (a rule that also matched its own target would loop a policy page), or a Worker script in front of the assets. Neither can be proven on production before 2026-11-11 without a deploy of its own, and the gain is only how a crawler labels the hop. Revisit after launch together with any other routing change. Cost if wrong: a search engine treats the slash-less address as a temporary move and keeps it in its index a little longer, although the canonical link and the sitemap already name the slash form.
