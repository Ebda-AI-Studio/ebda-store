# CI-FULL-MAIN-1

> Section: 2026-11-10 — main must always carry a recent, passing FULL CI run (launch 2026-11-11, branch `fix/ci-full-lane-green`)

Ruling CI-FULL-MAIN-1 - every push to main, a nightly cron (Mon-Sat 01:17 UTC) and the Sunday cron run the FULL lane of `.github/workflows/ci.yml` (build + full lint/typecheck, full unit, orphan tests, integration, the whole workerd suite incl. `apps/api/workers-test/route-sweep.test.ts`, e2e, builder e2e, audit) on hosted runners whether or not `EBDA_RUNS_ON` is set; mutation runs on the Sunday cron (or a ticked dispatch) only; a newer main push cancels a superseded main run (one concurrency group for pushes; PR, cron, manual runs and the deploy workflows are never cancelled by it); a red full lane on main opens or updates ONE issue labelled `ci-main-red` (plus the Telegram alert) and the next green full run closes it; the PR lane is unchanged (affected only). This SUPERSEDES Ruling CI-HOSTED-1 (2026-11-02, "a scheduled run is a no-op unless a self-hosted runner is configured") for `ci.yml`'s schedules only (other workflows that cite it, e.g. the daily drift check of Ruling MIGRATION-DRIFT-1, are unchanged), and the LEAN "push to main = guards only" split of SP4 task 9. Evidence: with `EBDA_RUNS_ON` unset the Sunday full lane silently never ran, and no full or e2e run passed on main between at least 2026-10-27 and 2026-11-10 (controller measurement; manual runs on 10-25 and 10-27 failed); the "GitHub Free, 2,000 minutes" premise is stale: the Ebda-AI-Studio org is on GitHub Enterprise (50,000 Actions minutes/month). Residual: a cancelled superseded main run also skips that commit's post-merge migration-order arm; the newer commit's guards and every PR's own guard still check ordering. Cost if wrong: if Actions minutes or runner queueing become the constraint (e.g. the Enterprise trial lapses to Free), main pushes queue full lanes that burn the budget; the fallback is to restore the push `if:` to guards only and keep the nightly, re-checking the arithmetic in `docs/ebda/ci.md`.
