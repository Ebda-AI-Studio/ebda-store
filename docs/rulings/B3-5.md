# B3-5

> Section: 2026-10-21 — Phase B3 Jasmine (B3-\*)

Ruling B3-5 — skin-type and concern chips are a source over store Tags (existing `Tag` / `ProductTag`), not a new model. `category-grid.source: 'tags'` renders `TagChips`; `GET /public/tags` lists tags with at least one active public non-deleted product (most used first, max 12) and `GET /public/products?tag=<name>` filters by exact tag name inside the same store (refused with `sort=on_sale`). `source` is a look-owned design key (`LOOK_DESIGN_KEYS`) so a look switch returns it to categories. Evidence: `tests/integration/tag-chips-source.test.ts` (tenant isolation, empty tag never a chip, same-named foreign tag matches nothing), `tests/unit/jasmine-variants-render.test.tsx`. Cost if wrong: a merchant who tags inconsistently gets uneven chips; a typed facet can replace the source later.
