# SEARCH-T11-1

> Section: 2026-10-15 — Phase B1 Qamar (B1-\*)

Ruling SEARCH-T11-1 — the embedding indexer never holds a database transaction across a Workers AI call, and an Inngest retry never pays twice. `search-product-index` (`apps/api/src/lib/inngest/functions/search-product-index.ts`) runs each round as three memoized steps: `plan-N` (under `runInStoreScope`: prune rows whose doc became NULL, read today's count, pick up to 25 stale products), `embed-N` (the provider call, no transaction, sleep-after-success), `write-N` (ONE `INSERT … SELECT … ON CONFLICT` statement). The write joins `products` and stores a vector only if the product is not deleted and its CURRENT doc still hashes to what was embedded, so an edit between read and write is never stamped with the old text (the edit's own reindex event re-embeds it). A run does at most 8 rounds (~200 products), then sends itself a continuation event. Step state (corrected in review round 1, measured with normalised 1024-d vectors rounded to 5 significant digits — halfvec keeps ~3.3): ~9.8 KB per product literal, ≤ ~240 KB per embed step, plus ≤ ~175 KB of docs per plan step (25 × ~3.5k chars, 2 B/char Arabic) — ≤ ~3.2–3.4 MiB per run, inside Inngest's documented limits of 4 MiB per step output and 32 MiB of run state (inngest.com/docs/usage-limits/inngest, read 2026-10-16), so the batch size stays 25; a round that writes nothing stops the run instead of spinning. A non-retryable `EmbeddingError` becomes a `NonRetriableError`; a retryable one is retried 3× by Inngest, then `alerts-failure-watch` raises a P1. Evidence: `tests/integration/product-index.test.ts` (12 cases on pg17 + pgvector, incl. the handler and the backstop on `ebda_app` with the tenant guard; replaying the handler with the same memo makes no second provider call); 7 mutants killed (no hash guard on the write, no active-store filter, daily cap ignored, no NULL-doc prune, model change not stale, unscoped plan step → `TenantScopeViolation`, autofill writer without the reindex call). Cost if wrong: none for data (a missed vector is found by hash within 6 h); a step-state limit hit would fail the run loudly.
