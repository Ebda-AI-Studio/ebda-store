Ruling SF-EXPIRY-1 (2026-11-16, money builder, issue #843) - a StoreFeature override can expire, and an expired override is ignored at READ time (no sweep): `FeatureService.rowsToMap` skips a row whose `expiresAt` is at or before now, so the feature falls back to the plan baseline; `wholesaleEntitledUncached` (the only other reader of override rows for a decision) applies the same rule. Evidence: before this a feature sold through an override (`bundles`, 1 row on prod D1 on 2026-11-15) never ended when the merchant stopped paying (audit S19). New nullable columns `expires_at` (NULL = never, so every existing row and the previous release behave as before: expand-only) and `reason` on `store_features`, in Postgres (`20261116000200_store_feature_expiry`) and D1 (`platform/0014_store_feature_expiry`, generated; the generator learned `latePrismaColumns` for a column that is in schema.prisma but reached production D1 after 0001, which `extraColumns` could only express for D1-only columns). The super-admin single-feature PUT replaces the whole override: an omitted `expiresAt`/`reason` means never expires/no reason, a past `expiresAt` is a 400 (use DELETE); the bulk PUT leaves both untouched; the admin matrix shows the expiry and edits it. Staleness class: the resolved map is cached 5 min and the public store payload 120 s on top and nothing writes at the expiry instant, so an expiry bites within that BOUNDED-stale window (documented at `rowsToMap`); the uncached wholesale/order path obeys it on the next call. A daily sweep was not added: resolve-time is enough, an expired row is inert and the matrix labels it. NOT in this PR: selling `bundles` through the add-on catalog (part of the unmerged purchase stack, #775 and its dependents), so today `bundles` is still granted by hand and the operator must set `expiresAt` (the field and UI exist; nothing forces it). Existing overrides (including the prod `bundles` row) have no expiry until an operator sets one. Cost if wrong: an expiry takes effect up to about 7 minutes late on cached paths; and an override nobody gave an expiry still lasts forever, exactly as today.
