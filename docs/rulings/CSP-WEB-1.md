# CSP-WEB-1

> Section: 2026-10-29 - Close sweep 2 (N4, `fix/storefront-csp-nonce`)

Ruling CSP-WEB-1 - the storefront (`apps/web`) ships a per-request nonce + `'strict-dynamic'` Content-Security-Policy with no `'unsafe-inline'` and no `'unsafe-eval'` in `script-src`; it supersedes the 2026-09-02 decision in `docs/architecture/storefront-csp.md` and Ruling SEC-4d. Why now: the 09-02 objections were a nonce forcing dynamic rendering and OneSignal needing eval. Measured 2026-10-29: 31 of 32 route files are `force-dynamic`, the live storefront answers `cache-control: no-store`, the build prerenders only `/_global-error`, `STOREFRONT_TENANT_ROUTING` is off by default; admin and Orders already run without eval (SEC-4b). Change: `apps/web/middleware.ts` mints the nonce, puts the policy and `x-nonce` on the request and the policy on every response (overwriting any client-sent value; the studio-host pages keep their own stricter CSP), the policy is built in `apps/web/src/lib/csp.ts` (removed from `next.config.js`), the root layout's dark-mode script and the marketing pixel scripts carry the nonce. Browser check (measured 2026-10-29): `scripts/qa/storefront-csp-check.mjs`, headless Chromium against a local `next start` reading the live demo data, 5 demo templates x ar/en x 21 pages plus a product page, public reads only: about 280 pages loaded, 0 CSP violations, 0 CSP console errors, 0 inline scripts without a nonce. Not loaded (45 s navigation timeouts, slow server renders, no CSP involved): a few storedemo-jasmine and storedemo-lamma pages and the jasmine product page. Not verified: a merchant with real marketing pixels enabled (the demo stores have none, so pixel vendor chains were only reasoned about, with `'strict-dynamic'` and the nonce prop), the OneSignal push-subscribe flow behind a real app id, and the live Cloudflare deployment (OpenNext runs middleware and the header on workerd; not deployed from here). Cost if wrong: a script we did not exercise is blocked on a storefront (pixels or push prompt silently fail); the revert is one commit, and `STOREFRONT_NEEDS_UNSAFE_EVAL` is a one-line switch. Accepted residuals: the opt-in worker HTML edge cache shares one nonce across visitors for its cache lifetime on those hosts, and a prerendered `/_global-error` has no nonce.
