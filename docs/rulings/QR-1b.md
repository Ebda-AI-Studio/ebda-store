Ruling QR-1b - a printed code carries a STATELESS storefront link (`/q/s`, `/q/w`, `/q/p/<slug>`, `/q/c/<slug>`); there is no short-link table. The storefront asks `GET /public/qr/scan`, which resolves the target (a renamed slug follows the slug-redirect table; WhatsApp reads the CURRENT store number) and counts the scan, then 302s with `utm_source=qr&utm_medium=print&utm_campaign=<kind>`. Cost if wrong: a merchant cannot retarget a printed code to a different product; they reprint it.
