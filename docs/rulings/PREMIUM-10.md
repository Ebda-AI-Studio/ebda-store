# PREMIUM-10

> Section: 2026-11-03 - Storefront premium defaults (PREMIUM-\*)

Ruling PREMIUM-10 - the Latin sub-label of a built-in lockup is `dir=ltr`, so an overflowing label truncates at its END ("MAR…") instead of the start ("…MAR") inside an RTL header. Cost if wrong: a very long label is still cut; it is cut at the right end.
