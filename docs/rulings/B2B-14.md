# B2B-14

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-14 (Task 8b; scope and entitlement amended by B2B-17 / B2B-18; the floor's shortfall amended by B2B-20) - the buyer's entitlement is snapshotted on the order line (`order_items.tier_ladder`, written by `priceSnapshot` from `Resolved.ladder` + `Resolved.groupPercentMinor`: `{ rungs: [{ minQty, priceMinor, variant, group }], groupPercentMinor }`, public tiers plus the buyer's active group tiers in scope, below base). A partial return reprices the KEPT units from that snapshot only (`productReturnAdjustment`, pure, `packages/shared/src/pricing/return-adjustment.ts`). Lines priced by the group percent or at base, a missing snapshot or a missing ladder never adjust; a snapshot in the pre-B2B-17 rung-array shape is treated as missing (only development databases hold one). The refund is floored at 0 (the buyer is never charged; the shortfall is reported to the merchant and, since B2B-20, carried forward to the product's next return), and a later return that lifts the kept quantity back over the threshold or returns the last units RELEASES the earlier retention, never more than was actually retained (so the sum of refunds can not exceed what was paid). The adjustment rides the same cumulative allocation the GL books (`allocatePartialReturn` `prevAdjustment`/`thisAdjustment`), so the provider refund, store credit and the journal stay one number; the per-item value is persisted in `return_items.tier_adjustment`. Cost if wrong: a line sold before the ladder snapshot existed is never adjusted, so a merchant who wanted the clawback on old orders must adjust by hand.
