# B2B-I4

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-I4 - revoke removes the buyer from EVERY wholesale group (to the default non-wholesale group, else none) and the response says `membership: removed | already_not_wholesale`. A buyer already moved out by hand closes the application and says so; it is not an error. Cost if wrong: a merchant who wanted "revoke only if still in the approved group" sees the buyer leave a different wholesale group they were moved to deliberately.
