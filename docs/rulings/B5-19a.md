# B5-19a

> Section: 2026-10-22 — Phase B5 Dahab (B5-\*)

Ruling B5-19a (Task 10) — fixed-amount wholesale tiers are excluded for gold products, a group PERCENT is not. The B2B wholesale program (`ProductPriceTier`, `PriceResolver`) landed on main after this plan was written, so "no B2B price lists exist" no longer holds. A fixed tier amount does not move with the rate, so within a day a discount tier would sit ABOVE a gold base price. Switching a product with tiers to gold is refused (409 GOLD_NO_PRICE_TIERS), and creating or editing a tier on a gold product is refused with the same code (`price-tier.service.ts`). A wholesale group percent applies to the materialised gold base like to any base. The order gate (Task 12) compares the recomputed gold price with the materialised BASE price, before `PriceResolver` discounts it. Cost if wrong: a jeweller cannot give a wholesale buyer a fixed per-gram price break; a group percent is the supported shape.
