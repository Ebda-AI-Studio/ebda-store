# B5-19

> Section: 2026-10-22 — Phase B5 Dahab (B5-\*)

Ruling B5-19 — exclusions that keep the money story single (Task 8 Zod + Task 12 guards). Excluded: a gold-priced product cannot be a bundle component (a bundle price is fixed while its parts drift; `BUNDLE_PRICE_NOT_ALLOCATABLE` would fire daily); gold mode forbids `compareAtPrice` / `discountType` / `discountValue` on the product and its variants (sales run through coupons/promotions); the return type `exchange` is refused for a line with a `gold_snapshot` (`GOLD_EXCHANGE_UNSUPPORTED`; return + new order instead). What refunds use. Refunds keep reading `order_items.price`, as `return.service.ts:439` does today. The snapshot is what the refund screen and the invoice line display. Switching modes. Switching gold → fixed freezes the last computed price as the fixed price and writes an audit row. Cost if wrong: no gold "طقم" bundle (sell the set as one product) and no struck-through gold prices.
