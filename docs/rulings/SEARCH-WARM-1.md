# SEARCH-WARM-1

> Section: 2026-11-11 - first search after idle (amends SEARCH-T12-1's flat 400 ms)

Ruling SEARCH-WARM-1 - option (b): the query-embed race is 1200 ms (`QUERY_EMBED_COLD_BUDGET_MS`) for an isolate that has not completed a query embed in the last 4 minutes, and stays 400 ms when warm; each successful embed logs `{cold, budgetMs, tookMs}` at info so the numbers can be re-tuned from `ebda-logs`. Option (a), a keep-warm cron, is rejected: `tests/unit/jobs-schedule.test.ts` and the schedule budget rule allow nothing under 30 minutes except `*/15`, a \*/4 cron would burn ~360 embeds/day plus DO budget round trips for nothing a shopper sees, and it cannot warm every isolate (a new isolate is cold regardless). Evidence (measured live, Amelia Aurum, 2026-11-11): uncached queries came back `meta.degraded:true` and took ~0.95 s total against a 0.51 s `/health` round trip, i.e. the whole 400 ms was spent and lost; the first call after a 4-minute idle was degraded while a following call in the warm isolate was not; the same query answered fully once its vector was in the isolate cache. The race timer covers the budget accounting (up to 8 AuthState DO calls) as well as Workers AI, so cold DO wake counts against it. Degraded answers are never cached as full: `public.routes.ts` skips the response cache when `meta.degraded === true` (around line 447-452), ranked lists answer `private, no-store`, and `tests/integration/hybrid-search-cache.test.ts` (SEARCH-T12-7) pins it; the list itself is the keyword order, which is a correct answer to the shopper. Cost: a cold search can now take up to ~1.2 s instead of 0.4 s before falling back to keyword results (one request per isolate per idle period); extra spend is zero calls (same single embed, same caps). NOT VERIFIED: the >= 95% non-degraded rate on a deployed build (no staging exists; workerd cannot reach Workers AI or the DO). Pre-fix baseline, live: idle trial 1 degraded. Re-measure after deploy with 8 idle trials spaced 4+ minutes (unique query each, `meta.degraded` absent = success). Cost if wrong: if the cold path needs more than 1.2 s, first searches stay keyword-only (today's behaviour); if a store receives bursts of cold isolates, each pays up to 1.2 s once.
