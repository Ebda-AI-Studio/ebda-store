# PREMIUM-4

> Section: 2026-11-03 - Storefront premium defaults (PREMIUM-\*)

Ruling PREMIUM-4 - rhythm. A product grid picks the desktop column count the product count fills (6 -> 3, 9 -> 3, 8 -> 4; `fitDesktopColumns`), applied to the featured-collection, base and Dahab grids; the existing L-05 centred last row (B1-40) still covers counts no column count fills, and no product is ever hidden. Carousel slides use the same 4-up width as the look carousels so the strip ends on a card edge; the tightest gap is 12px; the carousel pause control is a labelled text button under the strip (only when it autoplays). Cost if wrong: a merchant who chose 4 columns sees 3 for a 6-product section.
