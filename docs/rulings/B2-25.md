# B2-25

> Section: 2026-10-21 — Phase B2 Souq (B2-\*)

Ruling B2-25 (STOP-2 re-audit minors, 2026-10-21) — the second audit's P2s and R1/R2, fixed in one pass; M3 of B2-23 is no longer a residual. (1) Prices: the one storefront formatter (`useLocalePrice`) joins number and currency with a no-break space, so no price on any path splits at a line end; the pinned fixtures were refreshed for that one character. (2) Night tiles wrap in a centred flex row (seven categories end in a centred row of three, no left-hugging orphan). (3) Cart and checkout are look-specific, same markup and controls: Catalogue is the dense receipt (dashed flat summary, 5rem thumbs), Showroom the gallery (8.5rem thumbs, borderless raised summary, bigger title). (4) Showroom drops the `quiet` card-CTA mode (it hid the control on any sized product, so a variant card had no action); the card's own View / Add control stays on every card and is restyled as an outline by CSS. (5) One accent: the look sale chip reads `--chip-bg` / `--chip-fg` (accent pair by default, Night = the brass CTA metal) and the PDP discount pill uses the same chip on every look; red remains for errors and for stores with no look. (6) Showroom's new-in grid is 4-up from `lg` (2 on phones). (7) A stage whose product has no photo renders nothing, and a photo-less card on a look store is a shallow 2:1 placeholder. (8) R1: Dahab's root is a real `<header>` (the page's one banner) and `StickyHeaderOffset` measures ShopChrome's zone wrapper when it sticks, else the skin's header. (9) R2: every field type (Input, Select, Textarea, the Governorate combobox wrapper, and any `[aria-invalid]` field by CSS) draws its error boundary in the destructive INK, >= 3:1 on every look. (10) M3: the prominent search form follows the logo link in the DOM (a pure DOM move, the grid placement is explicit). The pack was shot against a production build (`next build` + `next start`, no dev badge). Cost if wrong: (1) a copy-paste of a price carries a no-break space; (4) a look that wants a hidden card action needs a new CTA mode, not `quiet`; (5) a merchant who wanted a red sale pill on a look store gets the look's chip.
