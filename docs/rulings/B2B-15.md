# B2B-15

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-15 (Task 8b) - a merchant may override the adjustment per return item (`refundOverrides[returnItemId] = { amountMinor, reason }`, 0 <= amount <= standard refund, reason of 3+ characters), only on a partial return, only with the `orders:refund` permission; it is previewed before confirming, persisted with the actor and reason (`adjustment_overridden`, `adjustment_override_reason`, `adjustment_override_by`) and audit-logged. An override changes only that return: later returns compute from the snapshots again, and a waived retention can not be released later. Cost if wrong: a merchant who overrides to refund in full on the first of several returns and then returns the rest sees the later returns priced as if nothing had been retained, so the total refunded can differ from a single-shot return by the waived amount.
