# SUBDOMAIN-SOON-2

Ruling SUBDOMAIN-SOON-2 - every coming-soon software product gets a `<label>.ebda.app` coming-soon page: crm, erp, invite, quote (Ahmad via the coordinator, 2026-11-10). crm and erp already had theirs (#283, unchanged). New: `invite.ebda.app` = «ابدأ إنفايت جاي قريب.» / "Ebda Invite is coming soon." and `quote.ebda.app` = «ابدأ ستوديو للتسعير جاي قريب.» / "Ebda Quote Studio is coming soon.", the names from `BRAND.comingProducts`. How: `invite` and `quote` join `STORE_EXTRA_RESERVED_SLUGS` (`packages/shared/src/hosts/reserved-slugs.ts`; the vendored foundation list stays untouched), so `parseStoreHost` calls them invalid and the storefront Worker's `unservedHostResponse` renders the studio page instead of looking up a store; `packages/shared/src/studio-pages` gains `invite` / `quote` in `ComingSoonProduct`, `COMING_SOON_LABELS`, the coming-soon lines and the site map's "next" list. The studio home's Invite and Quote Studio cards link to their pages like CRM and ERP (COMING-SOON-CRM-ERP-1); Ebda Ads has no subdomain page and no link. hub and id are unchanged. Evidence before (measured 2026-11-10): `quote.ebda.app` answered 404 "Page not found — Ebda Store" (`x-store-domain: quote.ebda.app`); `invite.ebda.app` answered 500 on three of four requests (one 404), also with `x-store-domain: invite.ebda.app`; the public API reports `STORE_NOT_FOUND` for both, so no store owns either slug. After: neither host reaches the store lookup (`x-store-domain` absent), so the 500 path is no longer reachable from these hosts; its root cause in the store-not-found path is not fixed here (diagnosed separately). Tests: `tests/unit/web-cross-tenant-cache.test.ts` (invite and quote are 200 coming-soon pages in ar and en with the exact headings, never a store), `tests/unit/store-host-resolver.test.ts` (never reach the database), `packages/shared/src/__tests__/hosts.test.ts` and `tests/unit/brand.test.ts` (reserved). Cost if wrong: a label someone wanted for a store slug is taken (low; the API reports no store with either slug, and the reserved-slug list is a one-line revert).
