# VE-14

> Section: Lifecycle emails and referral attribution (2026-10-22, branch `feat/lifecycle-emails`)

Ruling VE-14 (Task 8e, 2026-10-22) - `filterSidebar.bgColor` and `filterSidebar.textColor` are real layout keys. The storefront filter panel reads them (`ProductsClient`, `FilterSidebarSettings`) and the classic page builder writes them, but `storeLayoutSchema` listed only `enabled` and `defaultOpen`, so the layout PUT stripped both: a picked colour was saved and never rendered (the "saved but not showing" class the schema header warns about). They are now in the schema and in the page-settings panel. Cost if wrong: none beyond two optional colour fields on a store that never sets them.
