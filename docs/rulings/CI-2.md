Ruling CI-2 (Controller plan, 2026-10-28; enforced here) - no raw buyer PII ever enters the stream or leaves to an external model. The only buyer identifier is `buyerKey`; `data` is a STRICT per-type object (an extra key fails validation), every string in it is scanned for phone/email shapes (`assertNoPiiShapes`), the one free-text field (`returnReasonRaw`) is scrubbed to 200 chars with phones, emails and links masked, and customer-facing order payloads strip `buyerKey`/`areaKey` (`redactOrderForCustomer`). Cost if wrong: a rejected event (retried into the DLQ, pages) rather than a leaked field.
