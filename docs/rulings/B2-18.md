# B2-18

> Section: 2026-10-21 — Phase B2 Souq (B2-\*)

Ruling B2-18 (Ahmad, STOP-1, 2026-10-21) — Night souq's CTAs are BRASS `#C89B3C`; all three directions approved. This amends B2-2 for ONE token set only: the no-orange gate (hue 12-50, HSV saturation >= 35 %, B2-11) has a scoped exception for exactly the hex `#C89B3C` as `souq.night`'s primary CTA tokens (look token `primary`; composed theme `primaryColor`, `ringColor`; CSS variables `--primary`, `--ring`). Nothing else of Night (page, surface, ink, muted, line, accent, status inks), no other Souq look, no Qamar look and no other hex is exempt: a real orange or amber stays banned and an off-by-one brass is not the allowlisted hex. Brass keeps the contrast bars: dark ink `#10151C` on it 7.16:1 (>= 4.5), brass as text on the Night page 4.87:1 (>= 4.5), as a UI boundary on the page 4.87 and the card 3.65:1 (>= 3). The pomegranate chip fill (B2-2, B2-15 M1) is unchanged. `SOUQ_NIGHT_ALT_BRASS` and `looks/stop-alternatives.ts` (the STOP-1 alternative, B2-15 M4) are deleted: the alternative IS the default now, and a test pins that the module and every reference are gone. Evidence: `tests/unit/souq-look-tokens.test.ts` (exception passes only for souq.night CTA roles; the same hex fails on another look, on another Night role and on a non-CTA theme key; real oranges fail on Night primary; brass is in exactly one look token; contrast pairs). Cost if wrong: brass is orange-family adjacent; a merchant who switches to Night gets a warm brass CTA instead of the turquoise first proposed; reverting is one token edit and removing the allowlist. [Superseded in part by Ruling METAL-1 (Ahmad, 2026-10-22): the per-look exception is now ONE metal rule; see METAL-1.]
