# MKT-LEGAL-HTML-BUDGET-2

Ruling MKT-LEGAL-HTML-BUDGET-2 - 2026-11-10. `Worker dry-run (marketing)` failed on main-based PRs (seen on #523, no marketing change): css 16.1 KB > 16 KB on every page, and 12 legal pages over their html budget. The full lane never ran the job on main pushes, so it went unnoticed.

**CSS: trimmed, no raise.** 16.1 -> 15.9 KB gzip (16510 -> ~16.3k bytes) by deleting only rules that cannot paint: `.fx-ai*`, `.fx-lang`, `.fx-text` (markup removed in #130), `.ab-grid-3` (no element), the hand-written `.band-dark` in globals.css (the generated site-footer block in chrome.css sets the same values later), the `.np-soon` / `.np-badge` / `.menu-group .np-soon` / `.nav-services .np-txt` copies in services-chrome.css (the generated nav-products block in globals.css already sets them, #501), and three declarations a later same-selector rule overrides (`.dev-screen` background, `.rails ul` gap, `.sh-eyebrow::before` height/background). Proven identical by a computed-style fingerprint of every element (home, a service page, a legal page; ar + en; 390/820/1440 px) before vs after.

**Legal HTML: cause fixed, residual budgeted.** The growth is #510 giving every page JSON-LD; on these pages it ships twice (the script + its RSC copy). The Organization node carried the studio's offers (knowsAbout + makesOffer, ~1.3 KB raw); they now ride only the Services index graph, the other plain pages name the Organization by identity (same `@id` the home graph describes): -0.7 to -0.8 KB per legal page. Without any JSON-LD the pages measure exactly what SVC-BUDGET-1 recorded (/privacy 21.55 KB), so the remaining ~1.1 KB is the page's own structured data, which the route-walk test requires. No legal text changed. Budgets = local measured (flag OFF) + 0.5 KB rounded up to 0.5: /privacy 23.5, /en/privacy 22.5, /terms 25.5, /en/terms 24, /merchant-agreement 26, /en/merchant-agreement 24.5, /legal/whatsapp-terms 31.5, /en/legal/whatsapp-terms 29, /legal/whatsapp-dpa 23, /en/legal/whatsapp-dpa 22, /legal/whatsapp-privacy 23, /en/legal/whatsapp-privacy 22.

**Guard:** the marketing dry-run now runs in the full lane on every main push (`worker-dry-run` matrix falls back to the deployable workers when `changes` is skipped), pinned by `tests/unit/ci-marketing-budget-full-lane.test.ts`.

Cost if wrong: the 12 legal pages may grow up to ~0.5 KB gzip (one more paragraph) before the gate fires; no user-visible cost, and a further JSON-LD trim (address, description) is the next lever.
