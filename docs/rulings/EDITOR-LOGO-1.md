The audit's "cannot edit menu/logo/footer" is therefore half stale (menu + footer are built) and half a deliberate boundary. Evidence: one layer owns each write (form XOR page): the logo feeds emails, receipts, invoices and the PWA icon, not just the header, so a second writer inside a page draft would fork it from the live brand; the editor draft publishes through `store_page_revisions`, the logo does not. Cost if wrong: a merchant who expects to swap the logo inside the editor has to open Branding once.
