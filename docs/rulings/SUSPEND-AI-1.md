# SUSPEND-AI-1

Ruling SUSPEND-AI-1 (2026-11-20, Opus review of the AI spend gates: `assertStoreAiEnabled` / `assertAiQuota` did not look at the store's status) - an admin-suspended store (any status other than `active`) is refused AI spend, exactly like a store whose merchant turned AI off.

- The ONE spend gate is `assertStoreAiEnabled` (`lib/store-ai-switch.ts`), reached by `assertAiQuota` (every service call, bulk sweep, autopilot) and the HTTP guard `requireAiEnabled` (every `/ai` route). It now reads the merchant switch AND the store `status` in ONE uncached read (`readAiGate`) and refuses `403 STORE_AI_SUSPENDED` when the status is not `active` (an unknown status or a missing store fails closed), before the merchant-switch check and before any quota is counted or any slot is reserved.
- Staleness class: NEVER-stale (an account status). No cache, no TTL: a suspension is obeyed on the very next AI call and so is a reactivation. `isStoreAiEnabled` stays the pure merchant switch (the AI settings page and the assistant controls keep showing what the merchant chose).
- A background bulk job refuses at its first `assertAiQuota` (a sweep treats the refusal as "stop"), so it holds no spend; the per-store slot of #857 is reserved only after this gate, so a refusal never holds one.
- Evidence: `tests/unit/ai-store-switch.test.ts` (suspended / inactive / deleted / unknown status refused with the merchant switch on; the switch itself unchanged; the route guard refuses; a bulk `assertAiQuota` refuses before counting; a suspension between two calls is refused on the second), `apps/api/workers-test/merchant-orders-do.test.ts` "SUSPEND-AI-1" (real Worker + real Durable Object store: a super-admin suspends, `POST /ai/seo` is 403 STORE_AI_SUSPENDED, after reactivation it is no longer refused for the suspension).
- Cost if wrong: a store wrongly not `active` (a status value we do not know) cannot use AI until its status is fixed; support sees 403 STORE_AI_SUSPENDED. Too loose (the bug): a suspended store keeps spending the platform's AI budget.
