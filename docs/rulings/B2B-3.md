# B2B-3

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-3 — Resolution order (SUPERSEDED by B2B-3b below; kept for history). Candidates, after stripping tiers with `minQty > qty`: (1) tier for (variant, group) → (2) (product, group) → (3) (variant, all) → (4) (product, all); within a level the tier with the largest `minQty <= qty`. If no tier: group `percent_off` (basis points) on the base price; else base. Result is clamped to `[0, base]` (a tier above retail is rejected at write time AND clamped at read time) and group percent uses integer round-half-up on piastres (`Math.round(base * (10000 - bps) / 10000)`). Variant price = `variant.price ?? product.price` exactly as today; a product's own sale price is the base. Cost if wrong: a merchant expecting "lowest wins" sees a less-specific cheaper tier lose; the order line records `price_source` so it is explainable.
