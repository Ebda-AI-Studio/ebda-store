# VE-12

> Section: Lifecycle emails and referral attribution (2026-10-22, branch `feat/lifecycle-emails`)

Ruling VE-12 (Task 8a, 2026-10-22) - each product, collection and cart document has exactly ONE pinned main section (`product-main`, `collection-main`, `cart-main`), as Shopify has one main-product section per template. It can move; it cannot be removed, hidden or duplicated (reducer `PINNED`, validator `PINNED`), and a document without it is refused on every write. Extras (FAQ, reviews, bundles, recommendations, related, plus the shared image-text, newsletter, trust-badges, maker-profile) are ordinary sections, one each where the registry says `maxCount: 1`. A non-home document carries no header/footer group, theme, chrome, typography or page settings in the section tree (those stay on the home document and in page settings, 8e). Supersedes the finer-grained `product-info`/`buy-box` split in VE-3: the existing client components render as one block today, and splitting them is a later refinement, not a migration. Cost if wrong: a merchant cannot yet reorder the gallery against the buy box inside the product main section.
