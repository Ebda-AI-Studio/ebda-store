# MKT-SCRIPT-1

Ruling MKT-SCRIPT-1 - the studio home, the Store landing (`/store`, decoration only) and the Chat page carry a faint calligraphic texture built ONLY from our own name, the words "ابدأ" and "ابدأ ستوديو" (Ahmad 2026-11-03, after the prayer-mat reference). Hard rules: no Quran, no names of Allah, no religious phrases, no mosque, dome, minaret or crescent; only our own name. It is ONE static SVG, `apps/marketing/public/motifs/script.svg`, drawn once from glyph OUTLINES (the text is shaped with HarfBuzz and the outlines of the glyphs exported as SVG paths; there is no live text layer, no `<text>`, no font file shipped, nothing animated, never per letter). 105 instances of the two outlined words are laid along seven sinuous flow lines at six scales, rotated along the flow with jitter and overlapping, in silver `#8E959C` at 7-17 percent fill opacity (further 0.8 via CSS), used as a `background-image` behind the hero margins and one or two sections per page, so it is decorative and invisible to assistive technology. Font: Aref Ruqaa Bold (ruqaa calligraphy), SIL Open Font License 1.1, copyright 2015-2020 The Aref Ruqaa Project Authors, https://github.com/alif-type/aref-ruqaa, licence text kept at `docs/licenses/OFL-ArefRuqaa.txt`. The OFL allows use, including in artwork, without restriction on the output; no font software is redistributed or modified, so the Reserved Font Name is not used. Cost if wrong: if a reviewer reads the outlined glyphs as a redistributed derivative font the SVG must be redrawn from another outline source, a one-file change.

# MKT-FOIL-1

Ruling MKT-FOIL-1 - a worn gold-foil texture (`public/motifs/foil.svg`, a 256px tile: gold gradient plus two SVG turbulence filters for light and dark flecks) is used sparingly: the studio-home hero hairline and the two window product names, one or two headings on `/store` and on the Chat page, and the worn arch stroke (`arch-cap.svg`, turbulence-masked gold line). Everything else stays flat gold. Foil text is `background-clip: text`, so it stays real DOM text for screen readers and search; the tile's palette is held at or above 3:1 against the ivory ground for large text. Cost if wrong: a browser without `background-clip: text` support keeps the normal ink colour (the rule is inside `@supports`), no loss of content.

# MKT-ARCH-1

Ruling MKT-ARCH-1 - the generic pointed arch (a rounded-pointed profile, 96px rise, no dome, minaret or crescent) frames the Store and Chat windows of the studio-home hero (CSS `clip-path` polygon `--arch-poly-96` plus the `arch-cap.svg` stroke; the hero canvas clips its window lattices to the same profile), the Chat hero art (`--arch-poly-84`), and, as a gentle elliptical top, the plan cards on `/store` and the Chat page. Decoration only on `/store` (Ahmad overrides MKT-STORE-FROZEN-1 for decoration): no copy or layout change. Cost if wrong: a card badge near a corner could clip on an unchecked viewport; removing the `border-radius` rule restores the old cards.
