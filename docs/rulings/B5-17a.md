# B5-17a

> Section: 2026-10-22 — Phase B5 Dahab (B5-\*)

Ruling B5-17a (Task 12; deviations from the plan). (1) The MCP agent acknowledges a moved price with `place_order { acknowledgePrices: true }`, not a new `cart_acknowledge_prices` tool: a new write tool would change the agent-auth write classification, the denial alerts and their defences for no gain, and the flag is explicit (the agent saw `PRICE_CHANGED` and `view_cart`'s `priceChanged` / `previousUnitPrice` first). (2) The payment link runs the same gate, and re-checks the rate rows on the SAME connection as the order write (the request transaction) rather than a second money transaction: the customer row and the fiscal document live on the request transaction and a second one could not see them. (3) A null quote on a gold line (a cart line from before the product went gold) passes the quote check; the drift and stale checks still apply. (4) A dry-run quote does not refuse a moved price, it returns the new totals so the checkout can show "السعر اتحدّث" before payment. Cost if wrong: (1) an agent can accept a new price in the same call that places the order; (4) none.
