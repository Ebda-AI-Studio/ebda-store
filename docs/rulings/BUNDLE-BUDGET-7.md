# BUNDLE-BUDGET-7

Ruling BUNDLE-BUDGET-7 (2026-10-30, amended 2026-10-31) - the API Worker ceilings in `scripts/ci/worker-startup-budget.json` stay at 7,800,000 B raw / 2,200,000 B gzip; the integration does NOT raise them. The integrated tree (#366 + #300 + #327 + #365 + #324 + #328 + #325 + the 14 feature and fix PRs) first measured `worker.js` 8,150,690 B (BUNDLE-BUDGET-6 stack: 7,430,377 B). The +720 KB was feature code, mostly `@cantoo/pdf-lib` (460 KB) for the catalogue import. The trim: pdf-lib is built on its own by `scripts/ci/gen-pdf-lib-module.mjs` into `apps/api/src/cf/modules/pdf-lib.mjs` (version-pinned by `--check`; the three CATIMP-4 stubs apply) and uploaded as a separate Worker module (`find_additional_modules` + `rules` in `apps/api/wrangler.jsonc`). `normalizePdf` (the job step, never a request handler) loads it with a variable-specifier dynamic import, so the bundler leaves it out of `worker.js` and workerd evaluates it on the first PDF only. Measured after: `worker.js` 7,682,914 B (-467,776 B), under the 7.8 MB ceiling with 117 KB of room; the module is 593 KiB, so the total upload is 10,000 KiB raw / 2,990 KiB gzip (platform limit 10 MB gzip). Verified in workerd (Miniflare, compat 2026-08-01): the module loads under the uploaded name, `navigator.userAgent` is `Cloudflare-Workers`, and it creates, saves and re-loads a 2-page PDF.

Startup CPU: NOT improved measurably. On a loaded host (load average 12) the min of 5 runs was 159.6 ms after against 159.0 ms for the committed HEAD built in the same job (an earlier alternating run: 176.7 vs 212.6); the earlier 124 ms quiet-host figure could not be re-measured. The absolute 140 ms ceiling is enforced on quiet main/nightly runs; PRs use the relative gate. Candidates not taken (each a separate change): zod v4 locales 269 KB (`export * as locales` sits in zod's own `core/index.js` and `classic/external.js`, so a module alias cannot reach it; needs a zod patch or a bundler plugin), pdf-lib standard font metrics about 150 KB (now inside the separate module), `prisma-meta.json` 266 KB.

Cost if wrong: the dynamic import fails on the Worker (module not uploaded or renamed), and a catalogue-import PDF step fails with a job error (images and everything else are unaffected); `npm run -w apps/api cf:dry-run` lists the attached module, and `tests/unit/ops/pdf-lib-module.test.ts` pins its version.
