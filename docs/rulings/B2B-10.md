# B2B-10

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-10 (Ahmad, 2026-10-21) - A partial return that drops the kept quantity below the tier threshold ADJUSTS the refund. Refund = the paid amount of the returned units minus `(listPrice - paid unit price)` on the units KEPT, shown to the merchant before confirming, with an override. Specified in Task 8b. Cost if wrong: a buyer who returns a few units is refunded less than `price x quantity`; the merchant can override per return.
