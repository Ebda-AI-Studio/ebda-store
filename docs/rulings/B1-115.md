# B1-115

> Section: 2026-10-15 — Phase B1 Qamar (B1-\*)

Ruling B1-115 — the success toast uses the semantic SUCCESS token, never the brand colour; a look may override the token's value, not the choice to use it. Evidence: decision from the B1 minor pass (final-pr-review.md); the token keeps "it worked" readable across looks while each look's palette still sets the shade. Cost if wrong: a look whose success shade is low-contrast shows a weak toast until that look's override is fixed.
