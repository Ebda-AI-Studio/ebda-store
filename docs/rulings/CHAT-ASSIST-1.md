Ruling CHAT-ASSIST-1 (2026-11-23) - two owner-assistant RPCs on `WhatsAppBridge` for Ebda Chat's Smart Layer: `getTopProducts` (read) and `createCoupon` (write).

- `getTopProducts(storeId, asUserId, { period: today|7d|30d, limit 1..10 })`: owner or ACTIVE staff, role read LIVE (`memberRole`, never a token claim). Same numbers as the admin dashboard (`AnalyticsService.getTopProducts`); `today` = since Cairo midnight, 7d/30d rolling. Answers units + revenue in piasters; Chat renders numbers only from this answer.
- `createCoupon(storeId, asUserId, { code, type, value, startsAt?, endsAt | durationDays, usageLimit?, idempotencyKey })`: OWNER only (live), the `coupons` feature must be on (it is in every plan baseline, so this is the merchant's own switch, not a plan gate), creates through `CouponService.create` (no coupon logic duplicated). Guard rails stricter than the admin route: percentage 1-90, fixed <= 50,000 EGP (`MAX_FIXED_MINOR`), window <= 90 days and not in the past, usage limit <= 100000. Chat only calls it after the merchant pressed confirm on a preview card.
- Replay-safe: the same code with the same type/value/usage limit created in the last 15 minutes answers with that coupon (`replayed: true`, no second row, no second audit); any other existing code is `DUPLICATE_CODE`.
- Audit: `coupon.created` with `details.via = ebda-chat-assistant`, the idempotency key, and `before: null / after: {...}`; a failing audit never undoes the coupon (same as the coupon route).
- Rate limit: per-store per-method token bucket, per isolate (BOUNDED-stale: sheds a runaway caller, guards no money or permission); Chat also rate-limits per workspace before the call.
- Failures are data in the bridge envelope: `invalid` + `code` in FORBIDDEN, FEATURE_DISABLED, PERCENT_RANGE, FIXED_TOO_LARGE, WINDOW_ORDER, WINDOW_TOO_LONG, WINDOW_PAST, DUPLICATE_CODE, INVALID_ARGS; `unavailable` + RATE_LIMITED.
  Cost if wrong: a staff member or non-member could read best sellers only if the live role read were wrong (the owner role is checked for the write); a coupon discounts up to 90% for at most 90 days on one store, and the owner can switch it off in the admin at once.
