# DEMO-EDGE-1

> Section: 2026-10-22 — Phase B4 Lamma (B4-\*)

Ruling DEMO-EDGE-1 (Ahmad via controller, 2026-10-22; hardened after the #128 security review) — demo-store pages are served from the Cloudflare edge cache, cookieless visitors only. A Worker route runs before the zone cache, so `apps/web/demo-edge-cache.ts` (called from `sentry-worker-entry.ts`) uses `caches.default`: fresh 300 s, then served stale while one request refreshes, up to 86400 s; the client is told `Cache-Control: private, no-store` (the Worker caches internally; no office/ISP proxy keeps a copy) plus `x-demo-edge: HIT|MISS|STALE` and `x-demo-cache: hit|miss|stale`. Scope: the request URL's hostname must be EXACTLY `<label>.ebda.app` for a `DEMO_HOSTS` label (no case, trailing-dot, port or custom-domain variants; Host/X-Forwarded-Host/Forwarded/x-store-domain headers make it ineligible) AND the API store resolver must say that host is an active `isDemo` store (fail closed, remembered 5 min per isolate; run in parallel with the render of a MISS and gating the store, never on a HIT/STALE: a stored entry exists only after a passed verdict). Key: built by us from the canonical host, a `[A-Za-z0-9._~%/-]` path and only a single BUILT registry `look`; any other query key, unknown/malformed/repeated look, or odd path is ineligible. Per-visitor state: ANY Cookie header, Authorization, RSC/action/prefetch or non-HTML request is ineligible, so the stored body is the cookieless one by construction (the storefront server's only per-visitor inputs are the cookies `force-language`, `force-cookie-consent`, `force-preview-draft`). A visitor who has set the language or consent cookie is rendered live. Never stored: non-200, non-HTML, Set-Cookie. Real merchant stores and every ineligible request keep `private, no-store`. CACHE CLASS: BOUNDED-stale, residual <= 300 s for a demo catalogue/layout edit; no NEVER-stale data (price, stock, permissions) is decided from a demo page, checkout is refused. Evidence: one negative control per review finding in `tests/unit/demo-edge-cache.test.ts`. Cost if wrong: a demo page shows content up to five minutes old; the cost of the cookie rule is that returning visitors with a language/consent cookie get the live (slower) render.
