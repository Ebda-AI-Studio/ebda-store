# MKT-STUDIO-C-1

Ruling MKT-STUDIO-C-1 - the Ebda AI Studio home (`/`, `/en`) is direction C "living geometry", light: an ivory ground (brand gold mixed into near-white, no cream), near-night ink, a girih lattice in Ebda gold with brass and silver accents. First paint and `prefers-reduced-motion` / `save-data` / no-JS fallback is a static SVG poster (`GirihPoster.tsx`, in the HTML); the animation is ONE canvas from `public/studio-pattern.js`, injected by an inline loader after `load` + idle (so it is not in the up-front script list: the JS budget is unchanged), DPR capped at 2 at the full ratio (a first version also capped the backing store at ~3M pixels, which rendered the 1440 hero at 1.45x instead of 2x and blurred every line; that cap is removed), 30 fps, paused off-screen and in hidden tabs. Ebda Store (8-fold star) and Ebda Chat (6-fold star) are windows cut into the field. No text is ever drawn on the canvas. Perf budgets are NOT changed; the home HTML grows by the poster SVG and the new sections, estimated +2 KB gzip, to be confirmed on the CI static export (`npm run check:perf`). Cost if wrong: if the home HTML exceeds its 13 KB gzip budget the perf gate fails the PR and the budget needs a reviewed bump, no user impact.

Addendum (Ahmad 2026-11-03): small girih motifs (SVG files in `apps/marketing/public/motifs/`, wired in `src/app/motifs.css`, no JS) now decorate every studio-home section, the Chat page and, for decoration ONLY, the Store landing `/store`; Ahmad overrides the earlier store-landing freeze (MKT-STORE-FROZEN-1) for motifs: no copy or layout change there, motifs are absolutely positioned pseudo-elements. Cost if wrong: a motif can sit under a card edge on an unchecked viewport; it is decorative and removable by deleting `motifs.css`.
