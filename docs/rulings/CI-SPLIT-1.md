# CI-SPLIT-1

> Section: 2026-11-04 - use Umbra and GitHub CI together (branch `ci/split-hosted-umbra`)

Ruling CI-SPLIT-1 - light and deploy jobs run on GitHub-hosted runners, heavy test jobs stay on Umbra, selected by the repo variable `EBDA_RUNS_ON_LIGHT` (`runs-on: ${{ fromJSON(vars.EBDA_RUNS_ON_LIGHT || vars.EBDA_RUNS_ON || '"ubuntu-24.04"') }}`; unset = identical to today). Light = ci.yml `changes`/`guards`/`lint`/`typecheck`/`notify-failure`, gitleaks, blast-radius, deploy-change-label, semgrep, cf-schema-current and every cf-\*-deploy job (plan, deploy, notify); `timeout-minutes` <= 10 (deploy <= 20). Heavy (unit, integration, workerd, app builds, E2E, RLS, mutation) keep `EBDA_RUNS_ON`. Intended budget ~$10/month (about 1,250 Linux minutes at $0.008). **Evidence (measured, recent Umbra runs; hosted is about 1.5-2x slower plus npm ci, billed per job rounded up):** a PR push runs changes ~19 s, guards ~22 s, lint ~31 s, typecheck ~82 s, gitleaks ~11 s, blast-radius, label check, about 11-13 hosted minutes; a main merge runs guards-lite, gitleaks, one `plan` per path-matched deploy workflow (~4) and ~1.6 real deploys (web 139 s on Umbra, ~6 hosted min), about 16 minutes. Volume since 2026-10-28: ~37 CI runs/day (258 PR runs in 7 days), ~5 main pushes/day, so the estimate is ~$95/month for the PR-lane jobs plus ~$19/month for merges: the $10 budget fits only a much smaller set or a lower PR rate, and the first week of billing must be read before relying on it. **Cost if wrong:** hosted minutes exhaust the budget and light jobs stop running (required checks stay pending) - set `EBDA_RUNS_ON_LIGHT` empty (`gh variable delete EBDA_RUNS_ON_LIGHT -R Whisky-11/ebda-store`) and they fall back to Umbra.
