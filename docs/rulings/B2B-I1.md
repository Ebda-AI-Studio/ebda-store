# B2B-I1

> Section: B2B wholesale pricing (feat/b2b-wholesale, 2026-10-21)

Ruling B2B-I1 - a bundle with ANY wholesale-only component is not sellable and not visible to anyone in v1 (`resolveBundle` fails closed like a deleted component; the public bundle detail 404s so component names do not leak). Cost if wrong: a merchant cannot sell a wholesale-only bundle to approved buyers until bundles gain a buyer-aware path.
