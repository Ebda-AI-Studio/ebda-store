# WA-DOCS-1

Ruling WA-DOCS-1 - docs.ebda.app publishes the Ebda Chat developer docs (overview, connect your number, HTTP API, webhooks and connectors) in English at `/whatsapp/<slug>/` and Egyptian Arabic at `/ar/whatsapp/<slug>/` as a verbatim, sha-pinned import of the WhatsApp repo's `docs/site` (WhatsApp main 0976248 plus its PR 48, which removes two stale not-live sections of the Arabic API page and makes the webhook signature sample byte-safe; re-import from main once PR 48 merges, the bytes are the same); the Store never edits the text, a wrong sentence is fixed in the WhatsApp repo and re-imported (`node apps/docs/scripts/import-wa-docs.mjs <docs/site>` then update the pins in `tests/unit/support-wa-docs-drift.test.ts`). Evidence: the branch `feat/docs-whatsapp` was never opened as a PR and the live docs sitemap had no WhatsApp section; the re-import brought the API page up to date (plan_feature and plan_required errors, suspended and revoked-session answers, conversation search, payload limits). `tests/unit/support-wa-docs-drift.test.ts` (pins, word-for-word match) and `support-surfaces-live.test.ts` (pages built in both locales, linked and listed). Cost if wrong: the docs lag the product until the next re-import of the WhatsApp repo's docs.
