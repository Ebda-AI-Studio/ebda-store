Ruling ETA-3 (2026-10-27, coordinator) - a price-only refund (no goods lines) is issued as a Return Receipt Without Reference (RWR v1.2) using a REQUIRED merchant-chosen reason from the ETA list (I "International return receipt", B "Sales issued before adoption"; sdk.invoicing.eta.gov.eg/codes/return-with-no-reference-reasons-type/), picked on the order page only for stores with ETA connected; no reason is guessed or defaulted. Evidence: plan 11.2 item 8, `tests/unit/eta-receipt-service.test.ts`, `eta-receipt-mapper.test.ts`, `OrderEtaCard.test.tsx`. Cost if wrong: both reasons describe sales the ETA cannot reference, so the ETA may refuse an RWR for a sale it holds; that receipt is then `rejected` with the ETA's code and the merchant's accountant issues the credit outside Ebda.
