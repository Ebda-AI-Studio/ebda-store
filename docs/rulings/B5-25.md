> Section: 2026-10-22 — Phase B5 Dahab (B5-\*)

Ruling B5-25 — Dahab is LAST in `LOOK_TEMPLATES` (Task 6). The array's order is product behaviour: it is the order of the admin picker's tabs and of the demo bar, and through `defaultNewStoreLook` it decides which look a store gets when none is asked for. Dahab was listed first while it was designed (a designed template never shows); flipping its three looks to built would have made Dahab the signup default and the first tab, which nobody decided. The order is now Qamar, Souq, Jasmine, Lamma, Dahab, pinned by `looks-built-qamar.test.ts` and `LookPicker.test.tsx`. Cost if wrong: a merchant who wants Dahab first picks its tab.
