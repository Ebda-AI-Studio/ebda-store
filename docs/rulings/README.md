# Rulings

Every ruling lives in its own file, `docs/rulings/<ID>.md`. This folder IS the index: browse it, or
`ls docs/rulings` / `grep -l <term> docs/rulings/*.md`.
Form: `Ruling <id> - <decision>. <evidence>. Cost if wrong: <one sentence>.`

To add a ruling: create `docs/rulings/<ID>.md`. Nothing else. Do not edit this file, and do not add a
row or a count anywhere: a shared table/count made every two open PRs conflict (Ruling RULINGS-INDEX-1).
Never append to `docs/RULINGS.md` (frozen pointer; its entries were split out into this folder).
`tests/unit/rulings-index.test.ts` reads the files directly: it fails on an empty ruling file, a bad
file name, two IDs that differ only by case, or a table/count reappearing here.

Where an Ebda ruling (`R-EBDA-*`) and an inherited ruling disagree, the Ebda ruling wins in this repo.
