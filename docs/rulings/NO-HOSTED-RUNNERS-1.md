# NO-HOSTED-RUNNERS-1 - no workflow can run on a GitHub-hosted runner

Ruling NO-HOSTED-RUNNERS-1 - every `runs-on` in `.github/workflows` is a repo variable with a Mac-label fallback, never a hosted image: light jobs `vars.EBDA_LIGHT_RUNS_ON || vars.EBDA_RUNS_ON || '["ebda-mac-light"]'`, heavy and deploy jobs `vars.EBDA_RUNS_ON || '["self-hosted","ebda-mac"]'` (the retired PR-label `ci-umbra` route was removed in the next PR). `tests/unit/workflow-hosted-runners-only.test.ts` now pins the opposite of what it used to (SP4 task 9 / CI-UMBRA-1 "hosted fallback is the only allowed form"): it fails on any `ubuntu-` / `windows-` / `macos-` image name in a `runs-on`, and on any form that is not one of the three. Evidence: Ahmad 2026-11-16, never GitHub-hosted runners (no hosted minutes); measured on origin/main 2026-11-18: 89 `ubuntu*` references in this repo's workflows, 69 of them `runs-on` fallbacks (47 light, 22 heavy) that would silently take over when a variable is unset. Mutations: a hosted fallback in semgrep.yml fails the guard; reverting `max-parallel` fails ci-lean-structure. Cost if wrong: a job whose variable is unset waits for a Mac runner instead of running hosted (GitHub queues, it does not fail).

Consequences made in the same change (a Mac fallback makes them wrong otherwise):

- All 30 setup-node `cache:` inputs are removed: each was `... && vars.EBDA_RUNS_ON == '' && 'npm'`, i.e. the remote Actions cache exactly when the job would have run hosted; on the Mac pool it pulled 14 GB once and cost 1.5-2.5 min per restore. `ci-lean-structure` and `ci-npm-ci-reuse` now assert no `cache:` input at all.
- `app-build`'s `max-parallel` was `6` on hosted VMs and `1` otherwise: now `1` (one host per runner).
- 15 stale `# ubuntu-latest became 26.04 ... CI-HOSTED-2` comments (the hosted-image pin) are removed, and the CI header comment is rewritten.

Left alone on purpose, not a `runs-on` (historical evidence about past hosted runs): `ci.yml` comments on hosted `ubuntu-24.04` timings (lines about the 2,040 MB heap, the 16m47s coverage step, the 2,165 files). Not changed: `prod-smoke-journey.yml` now runs on the Mac pool instead of a hosted VM; it probes production over the public internet either way. The 15 `ci-umbra` route terms and the `CI_ROUTE` exemptions are removed in the follow-up PR `ci/remove-umbra-route` (Umbra retired 2026-11-14; Ruling CI-ROUTE-1 is marked superseded).
