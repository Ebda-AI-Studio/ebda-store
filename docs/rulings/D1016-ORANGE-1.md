# D1016-ORANGE-1

> Section: 2026-10-16 — Ahmad's product decisions (FU46-Y02a/b, D1016-\*)

Ruling D1016-ORANGE-1 (Ahmad 2026-10-16, "Ebda do not have orange") — the default store theme uses Ebda's palette (`BRAND.colors`): primary = night `#0A0B0C` (`210 9% 4%`) with white ink (19.7:1; `deriveBrandRoles` picks the same white, so stored and derived agree), accent = a gold tint `36 36% 95%` with dark-gold ink `36 40% 25%` (8.3:1), ring = gold `#B08D57` (`36 36% 52%`, 3.08:1 on white — the ≥3:1 non-text bar, measured). Night, not gold, is the primary because the primary fill carries every buy/checkout label and night with white is the strongest AA pair; gold stays the accent and focus colour. Dark-mode fallback: primary = lift `#CBA873` with night ink (8.7:1). The Modern template's own default (`TEMPLATE_THEMES.modern`) moves from orange to gold. Purged everywhere the orange was a default or chrome: `DEFAULT_THEME` (@ebda/shared) and the admin Branding `BASE_THEME`, the storefront `globals.css` fallbacks and gradients, the orders app chrome (now the admin's gold, night ink), the unused `force` orange palettes in the web/orders tailwind configs, the PWA default theme colour (admin + API, now `BRAND.colors.night`), the invoice and OG-image fallbacks (night), the swagger title (gold), the admin upgrade gate, staff badge, FAQ review box, AI usage chart, WhatsApp tabs (primary tokens), the platform landing glows, sparkles and WebGL tint (gold), the 500 page button (night), the demo and load-test seeds, the RLS-parity fixture and a smoke-script mail. Kept: a merchant's own colour (data), status hues (warning chips keep an orange/amber tint with dark ink), Mastercard's own red/orange in its icon (now its exact hexes), and the dead `COLOR_PRESETS` picker list whose "orange" (#FF6600) is a merchant option, not a default. Gate: `tests/unit/no-force-orange.test.ts` scans every tracked text file under apps/, packages/ and scripts/ (tests and docs excluded) for the Force hexes, orange HSL triplets (hue 20–35, saturation ≥ 90%, both syntaxes), the `rgba(255,110,1…)` glows, filled tailwind orange and the GL tint; allowlist = the AI eval fixture of a merchant's orange logo (shrink-only); and it pins `DEFAULT_THEME` to night/gold at AA. Red first: 99 hits on main. It sits next to `no-force-branding.test.ts` (strings) rather than inside it, because colours need their own matcher and allowlist. Cost if wrong: stores whose theme row was created with the old orange copied in still render orange (a stored value cannot be told apart from a merchant pick, Ruling FU46-W1c-9's same limit) — see D1016-ORANGE-2.
