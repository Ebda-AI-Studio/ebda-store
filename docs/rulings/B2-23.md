# B2-23

> Section: 2026-10-21 — Phase B2 Souq (B2-\*)

Ruling B2-23 (STOP-2 fix wave 1, 2026-10-21) — every finding of both independent audits. The a11y P1 and the taste P1s are fixed at the cause, platform-wide where the code is shared. (1) Focus Not Obscured (a11y P1-1): `StickyHeaderOffset` (mounted once in `ShopChrome`, every template) publishes the sticky header's height as `--header-h` and `html { scroll-padding-top }` keeps the focus scroll clear of it; the auto-hiding minimal header (Souq's) re-shows on focus and never hides while focus is inside it. `tests/souq/souq-focus-visible.spec.ts` drives Shift+Tab on two header heights and failed before the fix (12/12 cells). (2) Listing grid (taste P1-1): the cause was a 5-column grid with `spacious` frame padding (a 110px photo in a 170px card); a look may now ask `chrome.plp: 'autoFill'` (`repeat(auto-fill, minmax(11.5rem, 1fr))` from `lg`) and the Souq baseline frame is `compact`; the pack card is `h-full` so a row shares one height and the CTA (`mt-auto`) one baseline. (3) Mid-word breaks (taste P1-2): grep of every card path finds no `break-all` or `word-break`; `[overflow-wrap:anywhere]` only breaks a word that does not fit, so the break was a symptom of the 110px column. Fixed by (2) plus `[hyphens:none]` and `line-clamp-2` on the Souq card name; `anywhere` stays on the other packs. (4) Stage controls name their product and start with their visible text (2.5.3); the stage photo link leaves the tab order (R-12). (5) Home h1 for looks with no hero (sr-only store name). (6) Night error border uses the per-surface destructive ink at 2px (was 2.48:1). (7) Arabic price range reads "من X" (no dangling dash) and the sticky bar shows the lower price only. (8) No slug as a display name: the scenario seeds named stores by slug; they now get real names, a hero with no photo on a look store becomes a compact title band (`CompactHeroBand`), the Souq header name wraps to two lines instead of ending in an ellipsis, and `tests/unit/no-slug-as-display-name.test.ts` bans a name-to-slug fallback in storefront and API code. (9) Brass never dims on hover (the "dimmed Place order" was `hover:bg-primary/90` under a resting pointer). (10) Catalogue and Showroom checkout differ by summary thumbnail (3.25rem dense receipt vs 6rem); Catalogue's deal price strike draws itself once (static under reduced motion). (11) Copy: "بيتحسب عند الدفع", "تقسيط من X في الشهر على N شهرًا · تقريبي". (12) Minors: autoplay toggle uses one pattern (no `aria-pressed`), scroll arrows jump instead of gliding under reduced motion, the Catalogue rail gap and the Showroom top band are tightened, axe now also runs `wcag22aa` and `best-practice` (heading-order, page-has-heading-one asserted). Accepted residuals: a11y M3 (the prominent search DOM order; fixed afterwards, see B2-25) and M4 (inline Latin spec text is exempt from 3.1.2); the "Illustrative photos" strip is seed data written by `scripts/storedemo/seed.mjs` into the demo and local review stores' announcement bar only (no platform code emits it, so no real store carries it). Cost if wrong: M3 is a one-line DOM reorder plus a visual order test if an audit rules it a failure.
