# VE-10

> Section: 2026-10-22 — Visual editor (VE-\*)

Ruling VE-10 (Task 7, 2026-10-22) — a theme "reset to the look default" is a DRAFT edit (`null` in `PageDefinition.theme`), not a live `PUT /theme {key: null}`, and a typography snapshot lists every zone (`null` when unset). Evidence: VE-4 says no editor edit reaches the live store before Publish; the old reset flushed the draft and deleted the live key at once. A snapshot that listed only set zones would leave zones added later when rolled back. Cost if wrong: after a reset the live store keeps the override until Publish, and rolling back clears zones set after the snapshot (the point of a rollback).
