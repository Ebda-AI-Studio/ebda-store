Ruling CATIMP-4 - PDFs are parsed with `@cantoo/pdf-lib` 2.11.1 (MIT, published 2026-09-15, exact pin, Ruling P3-9), which counts pages from the page tree and re-emits a copy holding exactly the counted pages (scripts, open-actions and embedded files do not survive). Its three unused imports (culori, html-entities, node-html-better-parser, about 130 KB) are aliased to `src/cf/stubs/pdf-lib-unused.ts` in wrangler.jsonc. `fflate` 0.8.2 (already in the tree) is pinned for the inflate pre-scan. API bundle measured with `wrangler deploy --dry-run`: 8,180,611 B against the 8,300,000 B budget (8,307,373 B before the aliases). Cost if wrong: a pdf-lib upgrade that starts using one of the stubbed packages throws at call time; the bundle has 119 KB of headroom left.
