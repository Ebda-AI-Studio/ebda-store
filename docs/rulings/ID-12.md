Ruling ID-12 (2026-10-24) - a platform administrator (`super_admin`) is never granted over the Store API or the Accounts Service Binding RPC: `setRole` accepts only store_admin|staff, `PUT /admin/users` refuses promotion (409 OPERATOR_ONLY), `POST /admin/users` can only invite a store_admin. A super admin is created by an operator-run D1 statement. Evidence: Opus stage-3 review (any Worker in the account can call the binding). Cost if wrong: an operator needs a manual D1 statement to add a platform admin.
