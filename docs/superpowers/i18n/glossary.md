# Arabic Commerce Terminology Glossary

This glossary is the source of truth for translating e-commerce terms used in the Force admin dashboard. When the same English term appears in multiple places, its Arabic rendering must be consistent across the entire product.

If you encounter a commerce term that is not in this glossary, add a row with your proposed translation so reviewers can standardize before the term spreads.

## Conventions

- **Latin digits (0-9)** for money, SKU, IDs, order numbers, phone numbers. Arabic-Indic digits are acceptable only in free-flowing prose counts.
- **Brand name "Force"** stays in English everywhere.
- Some technical terms stay in Latin script because they are universally recognized in developer/commerce contexts (see rows flagged "keep Latin").
- For acronyms (COD, VAT, PWA), expand the full Arabic phrase on first use and optionally use the acronym thereafter.
